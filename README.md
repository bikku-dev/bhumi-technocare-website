# BHUMI TECHNOCARE — Website Redesign

Premium, responsive, high-performance web portal for **BHUMI TECHNOCARE** (formerly Sumit Computer), South Gujarat's premier IT hardware, chip-level laptop repair, CCTV security systems, printer care, and corporate Annual Maintenance Contract (AMC) service center.

---

## 🌟 Key Features

1. **Precision IT & Security Showcase**
   - **Laptop & Desktop Chip-Level Repair**: Component-level BGA repairs, screen/hinge fabrication, SSD speed boosters.
   - **CCTV & Electronic Surveillance**: 4K IP, ColorVu full color night vision, mobile remote monitoring, industrial warehouse coverage.
   - **Printer Maintenance & Toner Refilling**: HP, Canon, Epson, Brother laser and inkjet repair, cartridge supply.
   - **Corporate Annual Maintenance Contracts (AMC)**: Starter, Business Pro, and Industrial Enterprise plans with guaranteed 2–4 hr SLA.
   - **Network & Wi-Fi Infrastructure**: Structured LAN cabling, server racks, managed switches, mesh Wi-Fi.
   - **Data Recovery & System Security**: Hard drive recovery, licensed Quick Heal / Kaspersky antivirus suites.

2. **Hardware Deals & Product Catalog**
   - Business laptops (Dell Latitude, HP EliteBook).
   - Custom accounting/office PCs.
   - Complete 4CH/8CH CCTV camera kits.
   - Printers, high-speed NVMe SSDs, UPS backups, toner cartridges.
   - Dynamic search and category filters.

3. **Complete WhatsApp Enquiry & Ticket Engine**
   - Configured business WhatsApp number: **`+91 9316440985`** (and secondary `+91 9978817550`).
   - Collects customer name, phone number, entity type (Home / Corporate / Industrial), area/city (Kim Char Rasta, Surat, Ankleshwar, Bharuch, Kosamba), service/product of interest, priority/urgency, and fault details.
   - Auto-formats a professional structured ticket and launches WhatsApp directly.
   - Real-time formatted message preview & clipboard copy tool.
   - Available via both in-page section and instant modal popup from every service & product card.

4. **Location & Contact Integration**
   - Workshop address: **GF-11, Zam Zam Residency, NH-8, Kim Char Rasta, Kim, Surat, Gujarat - 394110**.
   - Dynamic live store status indicator (Open / Closed based on local business hours 9:30 AM – 8:30 PM).
   - Google Maps direct navigation link and interactive GPS card.

5. **Modern Tech Stack & UI**
   - Built with **React 18**, **Vite**, **Tailwind CSS**, and **Lucide React**.
   - Glassmorphic panels, dark cyber theme, responsive mobile drawers, and subtle status badge animations.
   - Curated high-resolution Unsplash placeholder images with resilient fallback handlers.

## 🚀 Running the Project

### Development Server
```bash
npm install
npm run dev
```
Visit `http://localhost:3000` in your web browser.

### Production Build
```bash
npm run build
```
Generates production-optimized assets in the `dist/` directory.

### Preview Production Build
```bash
npm run preview
```
